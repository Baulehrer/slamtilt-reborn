# Slamtilt - Reborn 1.3

Music playback is closer to the Windows original across all four tables. This release improves pitch slides and vibrato timing and expands checks of the original tracker and mixer through changing voices.

The Original/native PCM comparisons now cover about ten seconds per table under an adapted test clock. They are close but not sample-identical; complete songs, original device timing, sound-effect overlap and original Amiga playback are not fully verified.

Bring your own original Windows DAT files or a supported five-ADF Amiga set. Game files are not included.

- Windows: unsigned per-user installer and portable ZIP.
- Linux x86-64: AppImage and portable TAR.XZ.
- Browser: one offline HTML file; requires WebAssembly JSPI and a compatible browser.
- Linux ARM64: preview package for Raspberry Pi / Batocera.

Windows is tested with Wine and ARM64 with QEMU; physical hardware remains unverified. Check SHA256SUMS after downloading.
