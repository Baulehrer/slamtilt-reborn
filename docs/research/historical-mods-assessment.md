## Priority after research

1. Use WHDLoad/JOTD/DC-STFIX as a **bounded bug checklist**, especially the exact nature of Demon fixes. A fix for an Amiga invalid-memory optimization is not automatically a shared native rules bug.
2. Improve **Amiga installed-folder import**, starting with the accessible BTTR ZIP payload. Potentially covers installed/WHDLoad-derived user collections more broadly than a single modified disk set.
3. Add **HD-Ninja and other disk variants as compatible data inputs** when decoded assets/font layout can be verified cheaply. HD-Ninja is not currently supported; web evidence does not establish extra gameplay or an HD-remastered table.
4. Native **gamepad controls across menu/options/gameplay/highscore entry**, using the more complete WHDLoad control list as requirements.
5. Defer CPU/Workbench/reboot/crack infrastructure, duplicate archive formats and soundtrack-only artifacts.

Conclusion: no verified extra table, expanded rule set or improved physics was established in these historical-mod packages. The useful returns are broader imports, documented original defects and controller usability. Absence of documentation is not proof of identical gameplay.
