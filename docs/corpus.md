## Extraction limits

IPF and LZX/DMS not decoded in this pass. Amiga Action #83 disk 1 is not readable by xdftool. `nts_slamtiltcd.lzh` returns 7z exit 2: files must not be trusted until independently decoded. EU MODE1/2352 BIN and ROM IMG were converted by taking bytes 16..2063 of each 2352-byte sector; ISO extraction succeeds. Audio tracks were not interpreted. 1999 STR Demon is a separate Resurrection product and must not be treated as original Slam Tilt revision.

## Immediate reference choices

Use the unpacked 105592-byte Amiga `Game.exe` from retail ADF/JST/CD32, rather than RNC-packed WHDLoad payload. Use UK retail Windows game (466944 bytes), US retail (465920 bytes), and demo (252928 bytes). The 9.6 MB EU executable is InstallShield setup. RNC compression was identified by `file`; runtime packing of BTTR-HD remains a hypothesis.

`build/venv` contains amitools, pefile and capstone. Recreate with `python3 -m venv build/venv` and `build/venv/bin/pip install amitools pefile capstone`. Run `tools/corpus_extract.py` with Python and scan using `build/venv/bin/python tools/corpus_scan.py`. The generated tables deliberately retain unknown compiler/release fields rather than infer them from archive names.
