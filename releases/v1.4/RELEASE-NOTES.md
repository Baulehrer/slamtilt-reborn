# Slamtilt - Reborn 1.4

Music now retains voice state more faithfully across bank changes, jingles and queued music transitions on all four tables. This release also corrects a Mean Machines instrument-volume transition and adds original-mixer comparisons based on retained sound requests.

Bring your own original Windows DAT files or supported Amiga v1.224 five-disk ADF set. Original game files are not included.

- **Windows:** unsigned per-user installer and portable ZIP. Windows SmartScreen may warn about the unsigned installer.
- **Linux x86-64:** AppImage and portable archive.
- **Browser:** one self-contained HTML file; requires WebAssembly JSPI and a compatible browser.
- **Linux ARM64:** preview package for Raspberry Pi and Batocera.

Audio comparisons cover bounded reconstructed scenarios; complete gameplay timing, device output and Amiga audio parity remain unverified. Windows and ARM64 smoke tests use Wine and QEMU; physical hardware remains unverified. Check `SHA256SUMS` after downloading.
