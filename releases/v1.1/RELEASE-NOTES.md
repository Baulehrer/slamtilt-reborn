# Slamtilt - Reborn 1.1

Original-style menus, controller support and a much smaller browser download.

- Refreshed main/options menus with the original artwork, Reborn title and table previews.
- Native gamepad navigation and controls for all four tables, saved bindings and RT pull/release. Batocera launcher helpers included in the ARM64 preview.
- Single-file HTML reduced to about 3 MB; fixes the black/4×4 canvas in Vivaldi. Tested in Chromium, Vivaldi and Brave.
- Fewer lamp uploads for Space and Demon, with verified gameplay states and screenshots preserved.
- Smaller unsigned Windows installer and an optional compact Linux TAR.XZ download alongside AppImage.

Bring your own Windows DATs or supported five-ADF Amiga set. No original EXE is needed. Existing data/settings remain supported. Standard downloads keep the static engine; experimental shared-engine builds are not enabled.

Windows is tested under Wine, ARM64 under QEMU; physical Windows/Pi/Batocera hardware is unverified. ARM64 and browser remain previews. Windows/browser advanced native GPU filters are unavailable. See [Changelog](https://github.com/Baulehrer/slamtilt-reborn/blob/v1.1/CHANGELOG.md) and SHA256SUMS.
