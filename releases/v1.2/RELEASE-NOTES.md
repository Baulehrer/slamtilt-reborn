# Slamtilt - Reborn 1.2

Music playback and sound behavior are closer to the Windows original across all four tables. This release corrects table music startup positions and improves STIM sample timing, including when sound effects play alongside music. Mean Machines also receives sound handling and gameplay fixes.

Bring your own original Windows DAT files or a supported five-ADF Amiga set. Game files are not included.

- Windows: unsigned per-user installer and portable ZIP.
- Linux x86-64: AppImage and portable TAR.XZ.
- Browser: one offline HTML file; requires WebAssembly JSPI and compatible browser support.
- Linux ARM64: preview package for Raspberry Pi / Batocera.

Audio comparisons cover tested original scenarios and do not establish complete 1:1 playback. Windows was tested with Wine and ARM64 with QEMU; physical hardware remains unverified. Amiga uses the shared native engine and is not claimed to reproduce all Amiga-specific behavior.

Check SHA256SUMS after downloading. For changes and controls see the README and changelog.
